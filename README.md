# 가축 전염병 전파 예측 프로젝트

## 개요
- 가축 전염병 럼피스킨을 머신러닝 및 수학적 전염병 모델을 기반으로 전파 예측 결과를 제공합니다.
- 럼피스킨병에 특화된 정보를 안내하는 생성형 AI 챗봇 서비스를 함께 제공합니다.
